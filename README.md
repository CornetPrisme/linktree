# Personal Linktree Profile

A lightweight, custom-built "Linktree" style landing page to centralize all my important personal, professional, and athletic links in one place.

Project available on the website https://vblain.fr

<img src="/img/github-image.png" alt="Project screenshot"/>

##  Features

* **Centralized Hub:** Quick access to all my platforms from a single URL.
* **Custom Design:** Built from scratch without relying on third-party link-in-bio services.
* **Responsive:** Fully adapted for mobile and desktop screens.
